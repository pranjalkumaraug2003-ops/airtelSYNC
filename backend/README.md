# Udyam Digital API (Team 2Pointers, DTU)

Backend for **Project Udyam Digital**, Airtel SYNC 2026 Digital Track: a digital-first journey that lets a small business owner discover the right bundle, buy it and get it activated, on a phone, in their language.

- **Advisor**: Gemini turns free-text (any Indian language) into a structured business profile; a deterministic rules engine picks products and prices.
- **Quote**: one transparent monthly price, toggleable add-ons, every catalogue rule enforced on the server.
- **Smart KYC**: consent first, on-server OCR (OpenCV + Tesseract), GSTIN checksum and registry checks, catches all 7 planted problems in the 12 specimen applicants.
- **Tracker**: order stages with per-product dates and WhatsApp-style updates.
- **Partner console**: propensity model (AUC 0.70) ranks leads to call, with reasons.

Run: see `STEPS.md`. How it works: see `REPORT.md`. API docs: `/docs` on the running server.
